The game is called the astronaut game! You have 3 lives, a pause button, every 5 levels the background changes from day to a night background, character changes color each level, also every level gets faster and faster, and you can gain lives back!

I wanted to make a fun game that was similar to the dinasour game!

I made my project using pygame!

I struggled with getting the lives to work properly and the pause button. I learned how to draw pixel art and how to change the color of the player.
